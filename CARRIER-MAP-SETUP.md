# PULT+ — Нова пошта / Укрпошта та Google Maps

## Що змінилося

Після надсилання заявки на ремонт сторінка /repair-submitted.html дозволяє обрати Нову пошту або Укрпошту. Вибір зберігається на сервері для конкретної заявки.
Коли адміністратор налаштує точне відділення, клієнт бачить місто, відділення / індекс, повну адресу, карту Google Maps і посилання для маршруту.

ВАЖЛИВО: карта показує адресу публічного поштового відділення, але НЕ дозволяє автоматично надсилати пристрій. ПІБ та телефон фізичної особи-одержувача показуються лише після підтвердження менеджером для окремої заявки.

## Установка без втрати даних

1. Зробіть Backup робочої бази service_shop через pgAdmin.
2. У Query Tool цієї бази запустіть server/sql/carrier-choice-map.sql. Скрипт ідемпотентний та потребує попереднього shipping-setup.sql.
3. Він додає shipping_carrier_locations і repair_delivery_tokens, підтримку другого перевізника та двох форматів трек-номерів. Старі товари, замовлення, користувачі та заявки не видаляються.
4. Перезапустіть Node: node --env-file=server/.env server/app.js.

## Налаштування конкретних поштових відділень

1. Увійдіть у /admin-shipping.html як адміністратор.
2. Оберіть Нову пошту. Заповніть ПІБ одержувача, телефон, місто, точний номер відділення, вулицю та номер будинку.
3. Знайдіть саме це відділення в Google Maps. Скопіюйте широту й довготу позначки відділення (не міста).
4. Збережіть. Повторіть те саме для Укрпошти.
5. Якщо точних координат немає, карта в клієнта не відображатиметься. Не підставляйте приблизне місце або випадковий пункт у Яготині.

## Як це працює для клієнта

1. Клієнт оформлює заявку й на сторінці підтвердження вибирає перевізника.
2. Публічна адреса відділення й точна карта відображаються одразу, якщо адміністратор заповнив налаштування.
3. Менеджер переглядає заявку в /admin-shipping.html та підтверджує реквізити одержувача для її перевізника.
4. Клієнт натискає «Перевірити реквізити» і бачить ПІБ/телефон. Тільки після цього надсилає техніку.
5. Після фактичного відправлення клієнт додає трек-номер у /shipping.html.

Для гостьової заявки сайт видає випадковий приватний ключ лише у відповідь на створення ремонту й зберігає його у sessionStorage поточної вкладки. Сам код RP не дає права змінити перевізника або побачити приватного одержувача. Якщо ключ втрачено, зверніться до менеджера.

Нова пошта: трек-номер із 14 цифр. Укрпошта: 13 символів (https://track.ukrposhta.ua/). Статуси й накладні в PULT+ поки ведуться вручну — API перевізників не підключено.

## Перевірка

- Створіть нову заявку на ремонт без доставки у формі, на сторінці підтвердження оберіть Укрпошту, перевірте карту.
- До адміністративного підтвердження приватний ПІБ і телефон клієнту не показуються.
- Збережіть реквізити Укрпошти й підтвердьте заявку, перевірте у клієнта, що його обраний перевізник збігається.
- Перемкніть перевізника до відправлення — попереднє підтвердження повинно відкликатися.
- Після реєстрації трек-номера зміну перевізника має бути заблоковано.
- Перевірте UA/EN/RU, темну тему, акаунт і гостя на реальній PostgreSQL перед об'єднанням змін.
